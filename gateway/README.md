# Gateway Service

This directory contains the API gateway for the TravelMate project.

## Overview
The gateway routes requests to various microservices (e.g., TripService, UserService) and may handle authentication, rate limiting, and logging.

## Structure
- `src/main/`: Main gateway code
- `src/test/`: Tests
- `build.gradle`, `settings.gradle`: Gradle build configuration
