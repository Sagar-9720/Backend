# TripService

This service is part of the TravelMate project and manages trip-related data and operations.

## Overview
TripService is a Spring Boot microservice built with Gradle. It provides RESTful APIs for managing trips, including creation, retrieval, updating, and deletion of trip records. It can interact with both SQL (JPA) and NoSQL (MongoDB) databases.

## Key Features
- RESTful endpoints for trip management
- Integration with Spring Data JPA and MongoDB
- Validation and error handling
- Actuator endpoints for monitoring
- DevTools for development convenience

## Tech Stack
- Java
- Spring Boot
- Gradle
- JPA & MongoDB
